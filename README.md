# Выжимки

Сюда кидаются книги, которые нет времени читать целиком. Агент по [RULES.md](RULES.md) делает папку и выжимку **по главам**: суть того, что глава утверждает. Имя файла само говорит, что внутри (`Лесли-ЖБТ-02-знакомство.md`), чтобы скачать и унести.

Под конкретную проблему — папка [Боль](Боль/): туда сок из уже готовых глав, со ссылкой на главу. Книга под боль не переписывается.

Положить файл (`pdf`, `fb2`, `epub`) в корень этой папки и написать в чат: «обработай книги в Выжимки». Готовую главу не переписывают, пока не сказано «пересобери». Новая боль — «добавь в Боль: …».
