# Выжимки — протокол

Два слоя. Книга — суть по главам, как книга сама устроена. «Боль» — второй проход: из уже готовых глав собирается сок под названную проблему. Книгу под боль не переписывать.

Корень `Выжимки/` — входящие. Файл книги в корне (`pdf`, `fb2`, `epub`, `djvu`, `txt`) значит «ещё не обработана».

Повторный запуск не трогает готовый файл главы и готовый файл боли, пока не сказано «пересобери».

## Имена

Папка книги — короткое имя. Файлы называются так, чтобы скачать один и понять, что внутри:

- оглавление: `{Автор}-{код}-выжимка.md` — пример `Лесли-ЖБТ-выжимка.md`
- глава: `{Автор}-{код}-{NN}-{тема}.md` — пример `Лесли-ЖБТ-02-знакомство.md`
- шпора автора, если её читают отдельно: своя папка и `{Автор}-{код}-шпора-выжимка.md` плюс страницы `{Автор}-{код}-шпора-{NN}-{тема}.md`. Исходный pdf шпоры в git не класть
- боль: `Выжимки/Боль/{тема}.md` — пример `страх-подхода.md`

`код` — короткое узнаваемое сокращение названия, не полное имя файла исходника.

## Книга

Вопрос главы: что эта глава утверждает. Не «как это применить к сегодняшней проблеме».

В файл главы входит суть всех её крупных тем. Анекдоты, письма и каталоги из десятков шаблонов сжимаются до механизма. Дословных глав и длинных цитат нет. Полный извлечённый текст в папку не сохранять.

Файл главы:

- несколько предложений, о чём глава;
- блоки по её собственным темам: суть, когда это включается, что из этого следует.

Блока «не брать, потому что не про мою задачу» в книжных файлах нет. Приложения, письма и истории учеников — строка в оглавлении, что там лежит, без отдельного пересказа, пока не попросишь.

Шаги:

1. Найти в корне `Выжимки/` файлы книг без папки и оглавления.
2. Узнать название и автора. fb2 — XML FictionBook. pdf — текст через `pypdf` во временный файл вне папки, затем удалить.
3. Создать папку, перенести исходник.
4. Написать по файлу на каждую главу книги и оглавление со ссылками.
5. Строку добавить в `README.md`.
6. Пересобрать каталог читальни: `python3 scripts/build-catalog.py`. Список «ожидаемые книги» — вручную в `expected-books.json`.

Исходники (`fb2`, `pdf`, `epub`, `djvu`) в git не коммитить. Читальня — эта папка как репозиторий richbook, не весь LifeOS.

## Боль

Только под проблему, которую назвали. Новый файл в `Выжимки/Боль/`. Одна мысль — короткий абзац и ссылка на файл главы, откуда она взята. Это не второй пересказ книги.

Если боль пересекает несколько книг, советы из всех готовых глав кладутся в один файл боли.
